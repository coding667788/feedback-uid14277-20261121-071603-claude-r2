为跨机构账号入驻实现担保裁定。候选见证只证明某项材料（机构关系、到岗凭证或培训）的一类，并绑定申请版本及可信区间；每项材料可要求多份见证。担保人有稳定的人标识及所在机构，同一人跨机构别名归并后在整批中只能承担一份见证。每个申请设各机构可承担份数上限，以及必须排除的既往担保人集合。候选见证可覆盖多个申请，但同一批全局只能消费一次。申请可按优先级被选中或延期，但纳入的申请必须满足全部材料门槛且各材料消费的人互不相同。
allocate 固定逻辑时刻和待审版本，最大化已完整入驻的申请优先级总分，再最小化耗用见证成本，最后按申请 ID、材料 ID、见证 ID 的有序列表决胜。输出每个延期申请在保持其他入驻申请及原分配固定时，最多还能补齐几份见证以及未达标材料。accept 在单笔 SQLite 事务校验见证撤回、别名映射代次、申请版本和全局消费状态，保存整批决定；重复请求同结果，内容冲突拒绝。至少覆盖两个各自可行却共享一张担保证明的申请、跨机构同人、低成本占用导致总优先级更差、并发争用及事务中途退出后的重试。给出小规模穷举对照。

使用 Windows 原生 Python 3.12、标准库和 CPU，从空仓库实现，所有夹具用本地虚构数据。命令格式为 python -m solution <命令> CASE.json，涉及持久状态的命令带 --db DB.sqlite。标准输出为 UTF-8 JSON，同一逻辑输入产生同一结果；结构错误给出可定位的错误码及字段位置。交付可直接运行的样例、README（含完整输入输出定义与复现命令）和可用 python -m unittest discover -s tests -v 执行的断言测试。
